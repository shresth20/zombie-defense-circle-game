# Rules for every game project

- **Always apply the `localization_skill` skill** when creating or editing any game (HTML/CSS/JS): every text line and voice-over clip by key via `T('key')` / `I18n.voice('key')`, English only in `locales.json`, no hard-coded strings. Not optional — invoke it before writing the first line.
- **NEVER use the ElevenLabs API without explicit permission.** This is a strict, non-negotiable rule. Do not call the ElevenLabs API (REST, SDK, MCP connector, scripts such as voice/VO build tools, or any other route) — not to generate, re-record, test or "just check" anything — unless the user has typed exactly this sentence in the conversation: **"Yes I confirm use elevenlabs API"**. Any other wording (e.g. "go ahead", "yes", "do it") does NOT count. The confirmation applies only to the request it was given for; ask again for the next one. If a task would need ElevenLabs and the exact confirmation has not been given, stop, say so, and wait. Do not use the API.
- **Always apply the `animation-skill` skill** for any motion, transition, reveal or UI feedback in a game: GSAP bundled locally (no CDN), animate only `transform`/`opacity`, time-based motion, ease-out in / ease-in out, Skip button + `prefers-reduced-motion`, clean up timelines on unmount. Not optional — invoke it before writing any animation code.
- **Always follow `.claude/skills/folder_structure_skill.md`** when creating or editing any game: `index.html` at root, media in `assets/` by type (`fonts/`, `VO/`, `images/`, `videos/`, …), styles in `css/`, scripts in `js/`, text in `locales/`, build scripts in `tools/` if needed. Not optional — read it before creating the first file.
- **The game must be 100% offline, with zero external dependencies.** This is a strict, non-negotiable rule. Everything the game needs at runtime ships inside the game folder and loads by relative path: JS libraries (vendored, e.g. GSAP), fonts, images, sprites, audio, voice-over, locales and CSS. Never use a CDN, Google Fonts, remote images/audio, `http(s)://` URLs, `fetch`/XHR to any outside host, analytics/telemetry, third-party SDKs or any online API at runtime. Do not add package-manager dependencies that must be downloaded to run the game. Build tools (e.g. `tools/`) may run locally, but their output must be committed so the game never needs them to play. Before calling any game work done, check that no runtime file references an external URL and that the game loads and plays fully with the network turned off.
